Generate B2B Leads Automatically with n8n and Google Maps

By Laarbi BouskineSeptember 29, 20262 min read

B2B prospecting often starts the same way: searching for businesses on Google Maps, copying their details into a spreadsheet, checking they haven't been contacted already, then writing a message to each one. It's useful, but very repetitive.

Here is the n8n workflow I built to automate this prospecting: every Monday morning, it produces a list of new qualified prospects, each with a personalized message ready to go.

The problem: manual, disorganized prospecting

  • Hours spent searching for and copying contact details.
  • Duplicates: the same business contacted twice.
  • Generic messages, because there's no time to personalize them.
  • Information scattered across several files.

The solution at a glance

Every Monday→Target cities→Google Maps→Qualification→De-duplication→AI message→Database→Email summary

The workflow step by step

1. Two triggers

A Schedule Trigger runs the search every Monday at 9 am. A manual trigger also lets you run it at any time.

2. The list of target cities

A Code node holds the cities and the type of business to look for. The workflow creates one search per city.

3. Searching Google Maps

The workflow queries Google Maps through SerpApi. An alternative branch using Apify is ready if you want to switch providers. Results from each source are normalized into a common format, then merged.

4. Qualification

A Code node keeps only the businesses that match the criteria: category, website or phone number, rating, and so on. The criteria are adapted to each client.

5. Removing duplicates

The workflow fetches the leads already stored in Supabase and discards those that already exist. It then keeps the 30 best new leads of the week.

6. Personalized AI message

For each lead, a Gemini model writes a first outreach message tailored to the business (activity, city, website).

7. Saving and summary

New leads and their messages are saved to Supabase. A weekly summary is then sent via Gmail. A WhatsApp branch can also send this summary.

Tools used

  • n8n
  • SerpApi
  • Google Maps
  • Apify
  • Gemini
  • Supabase
  • Gmail

Things to watch out for

  • Prospecting rules: only public business data is used, and sending messages must comply with the applicable regulations (GDPR in Europe, Law 09-08 in Morocco), with an easy way to opt out.
  • Human review: generated messages are drafts. I recommend reviewing them before sending, at least at the beginning.
  • API costs: SerpApi, Apify and AI models have their own pricing. The weekly volume is easy to adjust to control the budget.

What this workflow brings

  • A new list of qualified prospects every week, without manual searching.
  • No duplicates: each business appears only once.
  • Leads centralized in a database, with a message ready for each one.

This workflow adapts to many industries: agencies, real estate, trades, B2B services… You only need to change the type of business, the cities and the qualification criteria.
