Automatiser la publication Facebook & Instagram avec n8n et l'IA

Par Laarbi Bouskine29 septembre 20263 min de lecture

Publier tous les jours sur Facebook et Instagram demande du temps : trouver une idée, créer un visuel, écrire la légende, choisir les hashtags, puis publier sur deux plateformes. Au bout de quelques semaines, la régularité baisse presque toujours.

Dans cet article, je vous montre le workflow n8n que j'ai construit pour automatiser entièrement cette tâche : chaque jour, à heure fixe, il prépare un post complet avec l'IA et le publie sur les deux réseaux, puis envoie une notification sur WhatsApp.

Le problème : une tâche simple mais chronophage

Pour une entreprise, une agence ou un créateur, la publication sur les réseaux sociaux se répète chaque jour avec les mêmes étapes :

  • trouver un sujet adapté à l'audience ;
  • créer une image ;
  • rédiger un texte et sélectionner des hashtags pertinents ;
  • publier sur Facebook, puis sur Instagram ;
  • vérifier que tout est bien en ligne.

Chacune de ces étapes peut être confiée à un workflow.

La solution en un coup d'œil

Planification→Audience→Hashtags→Image IA→Texte IA→Facebook + Instagram→WhatsApp

Le workflow étape par étape

1. Un déclencheur planifié

Un nœud Schedule Trigger lance le workflow chaque jour à la même heure. C'est ce qui garantit la régularité.

2. Le choix de l'audience

Un nœud Code sélectionne le segment d'audience du jour (par exemple familles, couples, voyageurs d'affaires). En changeant de segment d'un jour à l'autre, on évite des publications répétitives.

3. La recherche de hashtags

Le workflow utilise Apify pour analyser des hashtags Instagram liés au thème, puis un nœud Code extrait les plus pertinents.

4. La génération de l'image

Un modèle d'image de Cloudflare Workers AI crée un visuel original à partir d'une description. L'image est ensuite décodée puis envoyée sur Cloudinary.

Pourquoi Cloudinary ? Parce que l'API d'Instagram exige une URL publique pour l'image : elle ne peut pas recevoir directement un fichier.

5. La rédaction du post

Un modèle de langage (via OpenRouter) rédige la légende en tenant compte de l'audience et des hashtags. La réponse est demandée dans un format structuré, puis analysée par un nœud Code, ce qui évite les surprises au moment de publier.

6. La publication sur Facebook

Le workflow récupère le jeton de la page, puis publie l'image et le texte via l'API Graph de Meta.

7. La publication sur Instagram

Sur Instagram, la publication se fait en trois temps : création d'un « conteneur » média, attente du traitement de l'image, puis publication. Le workflow récupère enfin le lien du post publié.

8. La notification WhatsApp

Un nœud Merge attend que les deux publications soient terminées, puis une notification est envoyée sur WhatsApp avec le résultat.

Les outils utilisés

  • n8n
  • Apify
  • Cloudflare Workers AI
  • Cloudinary
  • OpenRouter
  • Meta Graph API
  • WhatsApp

Les points d'attention

  • Compte Instagram professionnel : l'API de publication fonctionne avec un compte Business ou Créateur relié à une page Facebook.
  • Jetons d'accès : il faut utiliser des jetons longue durée et prévoir leur renouvellement.
  • Limites de Meta : Instagram limite le nombre de publications via API sur 24 heures. Un post par jour reste largement dans ces limites.
  • Contrôle qualité : selon la marque, on peut ajouter une étape de validation humaine (par exemple un message WhatsApp ou email avec « valider / refuser ») avant la publication.

Ce que ce workflow apporte

  • Une publication régulière, même les jours chargés.
  • Des visuels et des textes cohérents avec l'audience ciblée.
  • Plus aucune tâche manuelle de publication : on reçoit simplement la confirmation sur WhatsApp.

Ce type de workflow convient aux commerces, aux agences qui gèrent plusieurs pages et à toutes les entreprises qui veulent rester visibles sans y consacrer du temps chaque jour.
