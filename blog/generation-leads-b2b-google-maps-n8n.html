Prospection & Leads

Générer des leads B2B automatiquement avec n8n et Google Maps

Par Laarbi Bouskine29 septembre 20263 min de lecture

La prospection B2B commence souvent de la même façon : chercher des entreprises sur Google Maps, copier leurs informations dans un tableau, vérifier qu'elles n'ont pas déjà été contactées, puis écrire un message à chacune. C'est utile, mais très répétitif.

Voici le workflow n8n que j'ai construit pour automatiser cette prospection : chaque lundi matin, il produit une liste de nouveaux prospects qualifiés, avec un message personnalisé prêt pour chacun.

Le problème : une prospection manuelle et désorganisée

  • Des heures passées à chercher et copier des coordonnées.
  • Des doublons : la même entreprise contactée deux fois.
  • Des messages génériques, faute de temps pour les personnaliser.
  • Des informations dispersées entre plusieurs fichiers.

La solution en un coup d'œil

Chaque lundi→Villes ciblées→Google Maps→Qualification→Anti-doublons→Message IA→Base de données→Résumé email

Le workflow étape par étape

1. Deux déclencheurs

Un Schedule Trigger lance la recherche chaque lundi à 9 h. Un déclencheur manuel permet aussi de la lancer à tout moment.

2. La liste des villes à cibler

Un nœud Code contient les villes et le type d'entreprise recherché. Le workflow crée une recherche par ville.

3. La recherche sur Google Maps

Le workflow interroge Google Maps via SerpApi. Une branche alternative avec Apify est prête si l'on veut changer de fournisseur. Les résultats de chaque source sont normalisés dans un format commun, puis fusionnés.

4. La qualification

Un nœud Code garde uniquement les entreprises qui correspondent aux critères : catégorie, présence d'un site web ou d'un téléphone, note, etc. Les critères s'adaptent à chaque client.

5. L'élimination des doublons

Le workflow récupère les leads déjà enregistrés dans Supabase et écarte ceux qui existent déjà. Il garde ensuite les 30 meilleurs nouveaux leads de la semaine.

6. Le message personnalisé avec l'IA

Pour chaque lead, un modèle Gemini rédige un premier message de prise de contact adapté à l'entreprise (activité, ville, site web).

7. L'enregistrement et le résumé

Les nouveaux leads et leurs messages sont enregistrés dans Supabase. Un résumé de la semaine est ensuite envoyé par Gmail. Une branche WhatsApp peut aussi envoyer ce résumé.

Les outils utilisés

  • n8n
  • SerpApi
  • Google Maps
  • Apify
  • Gemini
  • Supabase
  • Gmail

Les points d'attention

  • Respect des règles de prospection : on utilise uniquement des données professionnelles publiques, et l'envoi des messages doit respecter la réglementation applicable (RGPD en Europe, loi 09-08 au Maroc), avec une possibilité simple de se désinscrire.
  • Validation humaine : les messages générés sont des brouillons. Je recommande de les relire avant l'envoi, au moins au début.
  • Coûts des API : SerpApi, Apify et les modèles d'IA ont leurs propres tarifs. Le volume hebdomadaire se règle facilement pour maîtriser le budget.

Ce que ce workflow apporte

  • Une nouvelle liste de prospects qualifiés chaque semaine, sans recherche manuelle.
  • Aucun doublon : chaque entreprise n'apparaît qu'une fois.
  • Des leads centralisés dans une base de données, avec un message prêt pour chacun.

Ce workflow s'adapte à de nombreux secteurs : agences, immobilier, artisans, services B2B… Il suffit de changer le type d'entreprise, les villes et les critères de qualification.
